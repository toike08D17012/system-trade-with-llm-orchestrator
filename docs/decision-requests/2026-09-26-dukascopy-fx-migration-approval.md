# Dukascopy日足FXへの移行承認と利用条件の確認事項

## 利用者の承認

2026-09-26、repository-ownerはDukascopy FX移行の実装計画を承認した。
次の技術方針・内部制限について再承認は不要である。

- `dukascopy-node 1.50.0`を用い、USDJPYのUTCベースのBid日足終値を採用する。
- 株価の日付ラベルとFXのUTC日付ラベルを対応させ、参考USD換算に使う。
  東京市場の終了時刻や17時への整合は求めない。
- tick・1分足の取得、前日値やBOJ値による補完は行わない。
- 内部制限は同時数1、burst 1、最小間隔2秒、rolling 60秒につき30送信。
  provider公表上限とは区別し、自動retry・fallback・response cacheは無効にする。
- 実確認は2026年を先に取得し、2023〜2025年を追加する合計最大4 GET。
- 旧BOJ v1証拠の読取互換を維持し、新規証拠・価格結合はv2として保存する。
- 実装・検証・実確認結果の記録・コミットまでを対象とする。

## 確認事項と再開条件

必要なのは同じ技術計画の再承認ではなく、今回の自動取得・ローカル証拠保存を認める
提供者の許諾、または適用される別のAPI利用条件の確認である。
既に許諾がある場合は、その対象範囲と参照可能な根拠を記録する。
ない場合は、提供者への問い合わせで両方の利用方法を確認する。
利用者に代わる問い合わせ送信は実施していない。

確認できた条件をsource approvalに反映した後、承認済み計画の実装・検証・最大4 GETへ進む。
条件が計画と両立しない場合は、取得方法または取得元の変更を別途判断する。
