# 年次指標の内部計算結果

## 実装範囲

検証済み変更をコミットして続行する所有者指示に基づき、取得済み入力だけを使用した。
新たな通信・資料取得は行っていない。
財務統合CLIのprepare / validateへ`--calculate-annual`を追加した。
未指定時の出力形式・bytesは維持する。

対象は採用済み5年の年次値から計算する次の4指標に限定する。

| 指標 | 計算式 |
| --- | --- |
| 営業利益の売上比率 | 営業利益 / 売上 × 100 |
| 親会社帰属利益の売上比率 | 親会社帰属利益 / 売上 × 100 |
| 営業CFの売上比率 | 営業CF / 売上 × 100 |
| 売上前年比 | (当期売上 / 前期売上 − 1) × 100 |

Decimal精度28、ROUND_HALF_EVEN、小数6桁、単位percentを固定する。
外部Decimal設定を引き継がず、丸め後の負のゼロはゼロに統一する。
比率の分母・前年比の前期売上がゼロまたは負値なら欠損とする。
負の利益・CFは計算し、前年比の当期売上ゼロは-100%、負の当期売上も式どおり計算する。
前年比は開始日・終了日の月日が一致する1年差と、前期終了翌日の当期開始を両方要求する。
必須期間より前の売上、未採用値、比較できない期間は補完せず欠損理由を保存する。

## 保存と根拠

計算値を私的な`annual-calculations.json`へ保存し、manifestにはhash・件数・規則・制約のみを追加する。
原本・財務値・計算値はGit追跡対象外とする。
再検証済み採用値のdependency、values.json hash、期間・指標と全採用根拠参照を計算行に保持する。
同値の重複入力は根拠をすべて残し、異なる採用値・非有限値は計算を停止する。
既存inputs.jsonの参照と採用方針を経由して原証拠へ追跡できる。

これは内部成果物であり、P1の正規化evidence_idや`CalculatedEvidenceV1`の代替ではない。
ROE、株数依存の評価指標、一時損益調整、四半期差分は含めない。
